# Smart Recommendation System

A recommendation engine project powered by collaborative filtering and content-based techniques for movie suggestions.

## Project structure

- `data/raw/ml-25m/` stores the source MovieLens dataset
- `data/processed/` stores cleaned and transformed data
- `src/` contains all model and recommendation logic
- `models/` stores trained model artifacts
- `outputs/` stores charts, reports, and recommendation exports
- `notebooks/` holds exploratory analysis notebooks
- `app/` can host the web/API layer

## Setup

1. Create a virtual environment.
2. Install dependencies:
   `pip install -r requirements.txt`
3. Run the main pipeline from the project root.

## Notes

This project skeleton is intended for future development of a movie recommendation system using MovieLens data.
