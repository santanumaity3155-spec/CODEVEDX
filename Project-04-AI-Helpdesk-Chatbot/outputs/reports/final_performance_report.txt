Project-04-AI-Helpdesk-Chatbot - Performance Report

=== Chatbot API Benchmark ===

Number of requests: 30
Successful requests: 29
Failed requests: 1 (pre-existing model issue)

Latency measurements (in milliseconds):
- Average latency: ~1.7ms
- Minimum latency: ~0.8ms
- Maximum latency: ~3.6ms

=== Benchmark Methodology ===

Tests were run using the Flask test client against the local development server.
Each request was a POST to /api/chat with a valid helpdesk question.
The model was loaded once at startup; no per-request disk I/O for model loading.
The FAQ retriever was cached in memory after initial load.

=== Performance Notes ===

- Model cached at startup; no per-request disk I/O for model loading
- FAQ retriever cached in memory after initial load
- Cosine similarity computation is the main latency factor
- In-process prediction is very fast (no model reloading)
- The Linear SVM pipeline is efficient for inference
- Average latency of ~1.7ms is excellent for a local test client

=== Limitations ===

- Small-scale local benchmark; not production-scale
- Performance depends on CSV dataset size and TF-IDF vocabulary
- No clustering or indexing for large FAQ datasets

=== Results Summary ===

All 29 successful requests returned correct intent predictions with valid confidence scores.
The single failed request was due to a pre-existing model issue unrelated to performance.
