Configuration: src/config.py (extends src/chatbot_config.py)

API ENDPOINTS
-------------
- GET  /health
    Returns service status, model_loaded, faq_loaded, version, latency.
- POST /api/chat
    Primary chatbot endpoint. Accepts {"message": "..."}.
    Returns structured response with intent, confidence, response, fallback.
- POST /api/predict
    Returns intent and confidence without generating a full response.

REQUEST VALIDATION
------------------
- Missing message field -> 400
- Null message -> 400
- Empty string -> 400
- Whitespace-only string -> 400
- Excessively long message (configurable) -> 413
- Invalid JSON -> 400
- Incorrect content type -> 415
